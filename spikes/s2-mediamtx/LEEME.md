# `spikes/s2-mediamtx/`

**Dueño:** arquitecto → referencia para B1.

S2: MediaMTX v1.21.1 con el YAML como fuente única de las rutas (recarga por ruta, renombrado atómico, grabación sin backend, registro sin contraseñas). `resultado-macos-2026-10-05.json` es la salida real.

**Referencia:** Ejecutar: `.venv/bin/python spikes/s2-mediamtx/s2_mediamtx.py` (necesita `bin/mediamtx` y ffmpeg de pruebas).
